# 运动控制（ZMC）配置说明

> 适用版本：UTscan v2.8.4 备份仓库
> 硬件：众为兴 ZMC 运动控制器（`Hardware/Zmc/ZmcMotionController.cs`）
> 目的：说明运动控制系统的参数含义、配置方式与典型示例，指导启用与联调。
> 关联文档：[HARDWARE-CONFIG](HARDWARE-CONFIG.md)、[接线组装指南](接线组装指南.md)、[硬件移植使用说明](硬件移植使用说明.md)

---

## 1. 运动控制概览

### 1.1 控制器能力（代码实现）

- **连接**：以太网优先（`ZAux_OpenEth`，IP 来自 `ConnectionConfig.IpAddress`），IP 为空回退串口（`ZAux_OpenCom`，COM 口号）；
- **轴**：X/Y/Z/A/B 五轴（工程单位 mm/°，经 `UNITS` 换算）；
- **运动**：绝对/相对移动、回零（HOME）、急停、连续插补（MERGE）；
- **安全**：软限位（FS_LIMIT/RS_LIMIT）、断电位置恢复（VRF）、回零保护序列、急停回滚。

### 1.2 当前状态（重要）

**`enableMotionController: false`——运动控制处于禁用状态（当前调试阶段仅联调 DPR500 + Spectrum 两设备）**。

启用后：运动面板启用、扫查成像 F3 菜单启用、连接序列进入 ZMC 分支（连接→XYZ 使能→回滚保护）。

## 2. 参数含义（连接初始化序列）

连接时按固定顺序初始化（代码 L191-222），顺序不可乱，否则回零/限位失效有撞机风险：

| 序号 | 参数 | 代码常量/来源 | 含义 |
|---|---|---|---|
| 1 | `ATYPE` | 现场配置 | 轴类型（1=脉冲伺服） |
| 2 | `UNITS` | `ZmcAxisConfig.Units` | 工程单位换算（mm/° 每脉冲），写+回读校验（H-02） |
| 3 | `DECEL_ANGLE` | `0.2618` rad(15°) | 减速拐角 |
| 4 | `LSPEED` | `0` | 起始速度 |
| 5 | `SPEED` | `ConnectDefaultSpeed=100` | 默认速度（工程单位/s） |
| 6 | `ACCEL` | `ConnectDefaultAccel=500` | 加速度（工程单位/s²） |
| 7 | `DECEL` | 同 ACCEL=500 | 减速度 |
| 8 | `FS_LIMIT` | `ZmcAxisConfig.ForwardSoftLimit` | 正向软限位（工程单位） |
| 9 | `RS_LIMIT` | `ZmcAxisConfig.ReverseSoftLimit` | 负向软限位 |
| 10 | 原点/限位映射 | 说明书 §9.5 | DATUM/FWD/REV 输入口绑定 |

### 回零速度（L419-420）

| 参数 | 默认值 | 含义 |
|---|---|---|
| `HOME_SPEED` | 30 | 快速趋近原点开关 |
| `CREEP` | 5 | 慢速精找（单位=工程单位/s，现场确认） |

### 断电位置恢复（VRF，H-05）

- 掉电前 `DPOS`（需求位置）写入 VR0..4 断电保持区；
- 上电恢复 DPOS；**绝不写 MPOS**（编码器真实反馈，需回零建立基准）。

## 3. 配置方式

### 3.1 hardware.json（运行参数，仅连接与模式）

```json
{
  "ipAddress": "192.168.0.11",     // 控制器 IP（以太网连接）
  "port": 502,                     // 以太网端口
  "serialPort": "COM1",            // IP 为空时的串口连接
  "enableMotionController": false, // ★ 启用运动控制开关
  "triggerIo": -1,                 // ★ 扫查单次触发输出 IO（见 §5）
  "triggerPulseWidthMs": 5         // 触发脉冲高电平 ms
}
```

### 3.2 ZmcAxisConfig（运动参数，代码内现场确认值）

运动参数（速度/加速度/限位/单位/回零模式）目前是**代码内常量**，经 `ZmcAxisConfig` 传入（L54-59）：

```csharp
// 每轴典型配置（字段须现场确认）
ForwardSoftLimit = 150f,   // 正向软限位 mm（现场确认）
ReverseSoftLimit = 0f,     // 负向软限位 mm
HomeMode = 3,              // 3=SPEED正向找开关 / 4=反向
Units = 1000f,             // UNITS 换算（每脉冲工程单位）
```

> 注意：这些值当前硬编码在 `ZmcMotionController`/装配处；如需运行时调整，应迁至 hardware.json（列入重构建议）。

## 4. 典型示例配置

### 示例 1：启用运动控制 + 以太网 + 扫查触发

```json
{
  "ipAddress": "192.168.0.11",
  "port": 502,
  "serialPort": "COM1",
  "enableMotionController": true,   // 启用 ZMC
  "triggerIo": 7,                   // ZMC 数字输出口 7 → DPR500 External Trigger（现场确认接线）
  "triggerPulseWidthMs": 5
}
```

前置：ZMC 与工控机同一网段、防火墙放行、控制器网口灯亮；`ZmcAxisConfig` 限位/UNITS 按机械行程填好。

### 示例 2：调试期仅两设备（当前默认）

```json
{
  "enableMotionController": false,  // 运动禁用：跳过探测/连接，接口保留
  "useMock": false,
  "triggerIo": -1
}
```

### 示例 3：Mock 全仿真（无硬件开发）

```json
{ "useMock": true }
```

## 5. 扫查触发配置（TriggerIo 关键点）

- **语义**：`ScanService` 每点调用 `_motion.PulseTriggerOutputAsync(triggerIo, pulseWidthMs)` 产生单边沿脉冲 → DPR500 External 触发；
- **未配置拒启**：真机 + `TriggerIo < 0` → 扫查拒绝启动（防软件延时冒充单发，ScanService L174）；
- **保留口校验**：TriggerIo 不得占用伺服使能输出口（否则扫描中反复开关使能 → 失步/撞机，ScanService L144）；
- **接线**：ZMC 数字输出口 → DPR500 External Trigger Input（SMB→BNC）。

---

## 6. 注意事项

1. **安全序列**：连接即写 UNITS + 限位 + 原点映射，未执行前回零/限位失效——**切勿跳过连接直接回零**；
2. **回零建立基准**：上电后须回零（MPOS 为编码器真实反馈，DPOS 恢复不等于机械归零）；
3. **急停回滚**：连接中任一轴使能失败 → `EmergencyStopAsync` + 断开（MainForm L1243），现场先查轴状态；
4. **IO 冲突**：触发 IO 与使能口、限位口不得复用（代码已校验触发口，使能口须现场核对）；
5. **软限位**：Forward/Reverse 是扫查区域校验的单一来源（H-03），填错会导致扫查越界或拒绝；
6. **网络排障**：20008 类错误 = TCP 未建立，按 ping → 网段 → 防火墙 → 网口灯排查。
