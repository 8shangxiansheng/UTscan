# 超声显微扫查系统软件使用说明书

> 适用版本：v2.8.4
> 更新日期：2026-08-29

---

## 一、系统概述与运行环境

### 1.1 系统概述

超声显微扫查系统上位机软件（UTscan）驱动三台工业设备完成超声 C 扫成像检测：

- **数据采集卡**：Spectrum M3i.3242-exp（12-bit ADC，最高 500MS/s）
- **脉冲收发仪**：JSR DPR500（高压脉冲激励 + 接收放大）
- **运动控制器**：ZMC 系列（XY 运动台）

软件提供 A 扫实时显示、C 扫成像、B 扫截面、FFT 频谱、闸门分析、TCG 深度补偿、-6dB 定量、数据导出（CSV/ADTX）、历史回放、程序内更新等功能，并支持无硬件 Mock 仿真。

### 1.2 运行环境

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11（x64，经 WoW64 运行 x86 程序） |
| .NET | 无需安装运行时（自包含发布） |
| 硬件 | 工控机含 PCIe 插槽（M3i）、至少 1 个 RS-232/COM 口（DPR500） |
| 驱动 | Spectrum Driver CD（spcm_win32.dll）、JSR Control Panel SDK（JSR_Common3264.dll） |
| 架构 | x86（全部原生 DLL 为 32 位） |

### 1.3 硬件接线

```
DPR500 TRIG/SYNC ──(SMB→BNC)──▶ M3i 前面板 TRIG 口（主外部触发=EXT0）
DPR500 RS-232 Input ──(DB9→反转适配器→Rollover)──▶ 工控机 COM1
M3i CH1/CH2 ──探头信号──▶ 超声探头
ZMC ──以太网──▶ 运动控制器
```

**注意**：DPR500 的 TRIG/SYNC 必须接 DAQ 的 **TRIG 口**（非 X0/X1 多功能口），否则不触发。

## 二、安装与启动步骤

### 2.1 首次安装

1. 解压发布包 `dist\UTscan-win-x86` 到安装目录（建议纯英文路径，如 `C:\UTscan`）；
2. 安装 Spectrum 驱动（`drivers\spcm_drv_install_4.0.13877.exe`）；
3. 安装 JSR Control Panel SDK（`drivers\JSRControlPanelInstaller.3.3.0.0.exe`）；
4. 放置 `hardware.json`（含 IP/采样率/点数/触发 IO 等配置）到程序目录；
5. 双击 `UTscan.exe` 启动。

### 2.2 更新

- 程序内：主界面 帮助 → 检查更新 → 选择 `_update` 目录中的更新包 → 重启自动交换；
- 手动：整目录覆盖 + 校验 SHA256（`manifest.json`）。

### 2.3 配置文件

| 文件 | 作用 |
|---|---|
| `hardware.json` | 硬件连接参数（IP/采样率/点数/触发 IO/useMock 等） |
| `version.json` | 版本信息（随发布包） |
| `manifest.json` | 更新清单（逐文件 SHA256） |

## 四、核心功能操作流程

### 4.1 设备连接

1. 主界面 文件 → 连接（或启动自动连接）；
2. 连接对话框配置：IP 地址（ZMC）、连接超时(ms)、触发 IO、触发脉宽；
3. 点击确定 → 后台依次连接 采集卡 → 脉冲收发仪 → 运动控制器；
4. 状态栏 LED 指示：绿色=已连接，灰色=未连接，金色=仿真模式。

**连接后**：DAQ 自动启动连续采集；DPR500 默认关闭发射（安全设计）。

### 4.2 脉冲参数设置（脉冲页）

1. 设置 增益/PRF/电压/能量/阻尼/低通/高通/触发源；
2. 点击「应用参数」下发硬件（**注意**：应用参数会停止发射，需重新点「启用发射」）；
3. 点「启用发射」开始脉冲输出（**前提**：采集卡已运行，否则被安全限制拒绝）；
4. 「参数回读」显示硬件实际值（自动硬件回读）。

**脉宽**：由脉冲器硬件决定（RP-L2 固定），灰化不可编辑。

### 4.3 采集参数设置（采集页）

1. 设置 采样率(MHz)、采样长度(µs)、采样点数（三者联动）、量程、通道、触发延迟等；
2. 点击「应用采集参数」→ 停采 → 重初始化 → 自动重启；
3. 参数自动回写 `hardware.json`（重启后保持）。

### 4.4 A 扫显示与测量

1. 主界面 视图 → A 扫显示（F2）；
2. 波形实时刷新；顶部面板提供：
   - **闸门**：起始/宽度/阈值设置，框选测量区间；
   - **游标**：A/B 双游标读数（位置/幅值/时间差）；
   - **-6dB 定量**：自动搜索半功率点 → 缺陷尺寸；
   - **深度轴**：勾选「深度(mm)」切换 X 轴单位；
   - **叠加/平均/滤波**：多帧对比与显示平滑；
   - **回放/导出历史**：历史帧翻看与批量导出；
   - **全屏**（F11）：隐藏参数面板波形占满；
   - **增益条**：实时调接收增益（联动 DPR500）；
   - **TCG**：打开深度补偿曲线编辑器并叠加显示；
3. **冻结**：定格波形供离线分析。

### 4.5 扫查成像（C 扫）

1. 主界面 视图 → 扫查成像（F3）；
2. 设置扫查区域（起点/宽高/步距）、速度、成像模式、闸门、波形类型；
3. 可选启用 TCG（勾选「深度补偿」+ 编辑曲线）；
4. 点击「开始扫查」→ 运动台按光栅路径扫描，实时成像；
5. 暂停/继续/停止；停止后可「续扫」（从中断点恢复）；
6. 保存图像（bmp/png）、导出 ADTX/CSV。

### 4.6 B 扫截面

1. 主界面 视图 → B 扫截面（F4）；
2. 扫查过程中实时刷新，或扫查完成后自动更新；
3. 显示沿扫描线的截面（位置 × 深度），观察内部结构。

### 4.7 FFT 频谱

1. 主界面 视图 → FFT 频谱（F5）；
2. 显示当前 A 扫的幅值谱与峰值频率（确认探头频率/滤波范围）；
3. 可选「Hann 窗」抑制频谱泄漏。

### 4.8 数据存储与导出

| 操作 | 菜单 | 说明 |
|---|---|---|
| 导出 A 扫 CSV | 文件 → 导出 A 扫数据 | 当前帧逐点（index,time_us,voltage） |
| 导出历史 | A 扫窗「导出历史」 | 批量 CSV/二进制 .bin |
| 导出/导入 ADTX | 文件 → 导出/导入 .adtx | 扫查数据完整归档/回放 |
| 保存 C 扫图像 | 扫查窗「保存图像」 | bmp/png |
| 保存/加载设置 | 文件 → 保存/加载设置 | 面板参数（.acf） |

## 五、异常处理指引

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 采集卡连接失败 "打开设备 spc0 失败" | 驱动未装/卡松动/被占用 | 重装驱动、检查 PCIe、关闭其他 Spectrum 程序 |
| DAQ 应用参数报 "notify block size" | 通知块非 4KB 倍数（旧版） | 更新到 v2.0.7+（已修复） |
| A 扫显示"无触发：脉冲发射未启动" | DPR500 未启用发射 | 脉冲页点「启用发射」 |
| A 扫显示"无新帧" | 触发线断/DPR 未发射/增益过低 | 检查 TRIG 口接线、发射状态、增益 |
| 停止后再开始无响应 | DMA 残留（旧版） | 更新到 v2.8.3+（已修复 DMA 重建） |
| 点「启用发射」被拒 | 采集卡未运行（防无监控受激） | 先「开始采集」再启用发射 |
| DPR 连接失败 0x83F | 请求句柄数 > 实际设备数 | 更新到 v2.0.5+（已修复） |
| ZMC 20008 TCP 未建立 | 网络环境 | ping 192.168.0.11、静态 IP 同网段、关防火墙 |
| 日志查看 | `%APPDATA%\UTscan\utscan.log` | 程序文件日志，现场排查第一来源 |

## 六、参数配置说明

### 6.1 脉冲参数

| 参数 | 范围 | 说明 |
|---|---|---|
| 增益 | -13~66 dB | 接收器放大；增益条/A 扫实时调 |
| PRF | 100~5000 Hz | 脉冲重复频率；与采样点数乘积受 DMA 带宽限制 |
| 电压 | 100~330 V | 激励电压 |
| 能量挡位 | 1~4 | 激励能量 |
| 阻尼 | 4 档 | 探头阻尼匹配 |
| 低通/高通 | 3~50MHz / 0~12.5MHz | 接收滤波 |
| 触发源 | 内部/外部/Slave | 内部=自主 PRF；外部=ZMC 单边沿 |

### 6.2 采集参数

| 参数 | 范围 | 说明 |
|---|---|---|
| 采样率 | 9~500 MHz | 单通道上限 500，双通道 250 |
| 采样长度 | 0.1~10000 µs | 与点数联动 |
| 采样点数 | 16~1000 万 | 8 步进，与长度/采样率联动 |
| 输入量程 | ±200~10000 mV | 匹配回波幅度防削顶 |
| 触发延迟 | 0~10000 µs | SPC_TRIG_DELAY，跳过始波 |
| 触发电平 | ±10000 mV | X0 比较器阈值（默认 1000） |

### 6.3 TCG 曲线

- 横轴深度(mm)、纵轴补偿(dB)，折线插值；
- 拖拽控制点、双击加点、右键删点、「加」中点插入、重置；
- 勾选「深度补偿」才生效；A 扫可叠加曲线可视化。

## 七、维护与升级建议

1. **日常维护**：定期检查 M3i 驱动版本、DPR500 串口线缆、触发线缆（TRIG 口）；
2. **探头保养**：涂耦合剂、避免空载高压激励（防无监控受激已由软件拦截）；
3. **升级**：优先使用程序内「检查更新」；手动升级整目录覆盖 + SHA256 校验；
4. **配置备份**：`hardware.json` 是现场专属文件（更新通道不覆盖），换机需手工复制；
5. **日志归档**：`utscan.log` 定期备份，故障排查必备；
6. **真机校准**：TCG 曲线、-6dB 定量需参考块实测校准后投入使用。

## 九、常见问题（FAQ）

**Q1：A 扫没有波形？**
A：依次检查——(1) 采集卡 LED 绿色？(2) DPR500 是否已「启用发射」？(3) 触发线是否接 TRIG 口？(4) 状态栏显示"无触发"还是"无新帧"？

**Q2：波形幅值很小？**
A：增益调大（增益条或脉冲页），或降低采样卡输入量程（如 ±2000→±500mV）。

**Q3：波形削顶（平顶）？**
A：增益过高/量程过小，回波超过 ADC 满量程。降增益或加量程。

**Q4：改变采样长度后 A 扫窗口不变？**
A：应用采集参数后 A 扫采样长自动同步为实际采集时长（v2.6.0+）。

**Q5：扫查中点了停止，还能继续吗？**
A：可以。停止后「续扫」按钮出现（显示已扫百分比），点击从断点继续，数据不重复不丢失。

**Q6：如何确认探头频率？**
A：打开 FFT 频谱（F5），峰值频率即探头实测中心频率；可勾选 Hann 窗改善分辨。

**Q7：Mock 模式怎么开启？**
A：`hardware.json` 设 `useMock:true`，重启生效；模拟三设备无需硬件。

**Q8：增益条调节没反应？**
A：增益条需 DPR500 已连接；停止拖动后 300ms 才实际下发（防抖）。若仍未生效，检查「参数回读」是否显示新值。
