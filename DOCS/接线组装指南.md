## 1. 系统组成总览

```
                 ┌──────────────────────────────┐
                 │          工控机 (IPC)         │
                 │  PCIe x1 槽: Spectrum 卡      │
                 │  COM/RS-232: → DPR500 (JSR SDK)│
                 │  网口:       → ZMC 以太网      │
                 └───────┬──────────┬───────┬───┘
                         │ PCIe      │ RS-232│ 以太网
                 ┌───────▼───┐ ┌────▼────┐ ┌▼──────────┐
                 │ Spectrum   │ │ DPR500  │ │ ZMC       │
                 │ M3i.3242-  │ │ 双脉冲  │ │ 运动控制器│
                 │ exp 采集卡 │ │ 接收器  │ │           │
                 └───┬────┬──┘ └┬─────┬──┘ └┬─────────-┘
              CH0(SMB)│   X0│   │远程 │RS232│ 脉冲/方向 + 使能
                     │    │   │脉冲器│(RJ45)│ IN1~IN8(限位/原点)
                50Ω同轴│  同步│  │连接器│     │
                     │    │   └─┬───┘   ┌─▼──────────┐
                 ┌───▼────┴──┐  │       │ XY+Z 三轴   │
                 │ (直连,见§3)│  │       │ 扫描运动架  │
                 └───────────┘  │       └────────────┘
                          ┌─────▼─────┐
                          │ 超声换能器 │
                          │ (探头)     │
                          └───────────┘
```

信号链一句话总结：**换能器 ↔ DPR500（发/收）→ 接收输出 → Spectrum CH0 采集；DPR500 同步脉冲 → Spectrum X0 触发；工控机串口（经 JSR SDK）控 DPR500、网口控 ZMC。**

## 2. 各设备接口定义

### 2.1 Spectrum M3i.3242-exp 采集卡（PCIe）

| 接口 | 类型 | 用途 | 电气规格 |
|------|------|------|----------|
| CH0（模拟输入 0） | 前面板 3mm SMB 公头 | 接收 DPR500 接收输出（RF 回波信号） | 量程 ±200/500/1000/2000/5000/10000 mV 6 档；50Ω HF 路径带宽 250MHz（本项目默认），1MΩ 缓冲路径 125MHz |
| CH1（模拟输入 1） | 前面板 SMB | 第二探头/第二通道（软件 `ChannelMask` 双通道，需双通道时采样率自动减半为 250 MS/s） | 同 CH0 |
| X0（多功能线 0） | 前面板 SMB | **外部触发输入**（DPR500 TRIG/SYNC 同步信号） | 输入阻抗 10kΩ 上拉至 3.3V；电平：低 ≤0.8V、高 ≥2.0V；最高 +5V |
| X1（多功能线 1） | 前面板 SMB | 备用（TTL 触发/数字 IO/触发输出，软件 `ConfigureXLine` 可配） | 同 X0 |

**软件默认配置（`SpectrumDaqCard`，初始化后即生效，一般无需改动）**：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 采集模式 `AcquisitionMode` | **FifoMulti**（Multiple Recording） | 每触发一段（段长=SampleCount），帧边界与 DPR500 PRF 触发一一对应（P1-2 整改） |
| 输入量程 `InputRangeMv` | ±2000 mV | 按 DPR500 输出幅度调整（见 §3.1） |
| 输入路径 `InputFiftyOhm` | true（50Ω HF） | 兼作 DPR500 的 50Ω 端接 |
| 通道 `ChannelMask` | CH0 单通道 | 双通道需置 0x3 |
| 时钟 `ClockSource` | InternalPll | 外部时钟/外部参考时钟为高级选项 |
| 触发 | X0 上升沿，电平 1000 mV | 适配 DPR500 3~5V 正同步脉冲 |
| 时间戳 `EnableTimestamp` | 关 | 编码器触发扫查位置关联时开启（需 Timestamp 选项） |

安装注意（硬件手册 §Hardware Installation）：
- 全长卡（312mm × 107mm），需要 **全长 PCIe 槽（x1/x4/x8/x16 均可）**；部分 x16 槽仅限显卡，插不识别时换槽。
- 功耗约 23W（3.3V/12V 取自插槽），**必须保证机箱风道对卡表面吹风冷却**，不要堵风道。
- 远离电源与显卡等噪声源，**不要紧邻显卡插槽安装**（模拟采集易受干扰）。
- ESD 防护：插拔卡、接线前先释放静电（摸机壳/戴防静电手环）。

### 2.2 JSR DPR500 双脉冲接收器

后面板接口（DPR500 手册 §电源开关、指示灯和连接器）：

| 接口 | 类型 | 用途 |
|------|------|------|
| CHA/CHB 远程脉冲器连接器 | 模块化（多芯）连接器 | 供电 + 数字控制 + 高压 + 50Ω 信号回路，接换能器电缆（经远程脉冲器模块） |
| CHA/CHB Receiver Output（接收输出） | **SMB 插座** | 接收放大后的 RF 回波信号输出，**必须 50Ω 端接**（接 Spectrum 50Ω 输入即满足） |
| CHA/CHB TRIG/SYNC（触发/同步） | SMB 插座 | 内部 PRF 振荡器触发时：输出正极性同步脉冲（触发采集卡）；EXT 模式时：接收正向 3~5V 外部触发脉冲（上升沿有效），输入阻抗 50Ω |
| RS-232 Input（RS-232 输入） | **RJ45 插座** | 远程控制入口：**DB9→RJ45 适配器 + 八芯反转（Rollover）RJ45 电缆**连接工控机 COM 口；串口参数 4800、8N1、无流控（SDK 内部处理） |
| RS-232 Output | RJ45 插座 | 多台 DPR500 雏菊链级联（本项目单台，不用） |
| AC 输入 | 三芯电源插座（带电压选择开关 + 0.4A 250V 保险丝） | 100/120/220/240V，按国内市电选 **220V** 档 |

前面板：主电源拨动开关、POWER 琥珀色指示灯、PULSE 红色脉冲指示灯（发射时点亮）。

**软件控制方式（重要）**：DPR500 经 **JSR Common API SDK**（`JSR_Common3264.dll`）控制，无需自行实现串口协议。连接流程（`Dpr500Controller.ConnectAsync`）：
1. 检查 SDK DLL 可用（未安装则提示运行 JSRControlPanelInstaller）；
2. `JSR_OpenLibrary` 搜索 DPR500 设备 → 找到则真实连接；未找到**自动降级仿真模式**（`JSR_LIB_OPTION_SIMULATE`），软件仍可运行与测试；
3. 读取仪器/通道句柄、动态参数范围（增益/PRF/电压 limitLo/limitHi）、滤波器表、型号信息；
4. 全参数下发（`ApplyParamsAsync`）经 `JSR_SetDouble/JSR_SetInt32` 完成。

> 安装 SDK：运行 `超声脉冲发生接收器/JSRControlPanelInstaller_3_3_0_0/JSRControlPanelInstaller_3_3_0_0.exe`。
> 32 位应用加载 `JSR_Common3264.dll`（位于 `C:\Windows\SysWOW64\`），需 **x86 进程**（本项目 csproj 已固定）。

### 2.3 ZMC 运动控制器（正运动）

| 接口 | 用途 |
|------|------|
| ETH 以太网口 | 与工控机网口直连或经交换机（出厂默认 IP 以控制器标签/手册为准，软件内可配） |
| IN0~IN8 数字输入 | 原点/限位传感器（见 §4.3 映射表；软件按常闭/常开已统一极性配置 `INVERT_IN(0-8)=0`） |
| OP8~OP11 数字输出 | 各轴驱动器使能/抱闸控制（连接时软件默认全部断开，逐轴使能） |
| 脉冲+方向（或总线）输出 | 接各轴步进/伺服驱动器 |
| 24V/控制电源端子 | 供控制器与 IO；驱动器动力电另配 |

**软件连接方式**：IP 非空 → 以太网（`ZAux_OpenEth`）；IP 留空 → 串口回退（`ZAux_OpenCom`，COM 号取 `ConnectionConfig.SerialPort`，如 "COM3"→3）。

## 3. 核心信号链接线（三条同轴 + 一条串口 + 一条网线）

### 3.1 回波信号：DPR500 → Spectrum CH0

```
DPR500 后面板 [CHA Receiver Output, SMB母头]
        │  50Ω 同轴电缆（SMB 转 SMB）
        ▼
Spectrum 卡前面板 [CH0, 3mm SMB公头]
```

- Spectrum 端用 **50Ω HF 输入路径**（软件 `InputFiftyOhm=true` 默认开启），既是 DPR500 要求的 50Ω 端接，又获得 250MHz 满带宽。
- 量程建议：按 DPR500 手册把接收输出调到 **±2~±5V 峰值**，对应选 `InputRangeMv = 5000`（±5V）；小信号低噪声场景可降档到 ±2000/±1000mV。
- 若用 CHB 通道（第二探头），同理接 CH1，并把 `ChannelMask` 置双通道（采样率上限减半至 250 MS/s）。

### 3.2 触发同步：DPR500 → Spectrum X0

```
DPR500 后面板 [CHA TRIG/SYNC, SMB]
        │  50Ω 同轴电缆
        ▼
Spectrum 卡前面板 [X0, SMB]
```

- DPR500 设为 **INT（内部 PRF 振荡器）触发**：TRIG/SYNC 输出正极性同步脉冲，Spectrum 在其上升沿触发采集（软件已配 X0 上升沿、电平 1000mV，适配 3~5V TTL 同步脉冲）。
- 若将来需要外部触发 DPR500（EXT 模式），同一接口变为输入，需提供正向 3~5V 脉冲。
- **这是整条链路的时序基准：一次触发 = 一条 A 扫。**

### 3.3 换能器：探头 → DPR500

- 换能器电缆接 **CHA（或 CHB）远程脉冲器模块化连接器**（收发合一探头）；分置式发/收探头分别接对应通道。
- 接触式检测时探头与样品之间加声耦合剂（耦合膏/水浸）。

### 3.4 控制：工控机 → DPR500（RS-232，经 JSR SDK）

```
工控机 COM 口 (DB9 公头)          ← 或 USB-RS232 转换器（虚拟 COM）
        │  随机附带的 DB9→RJ45 适配器
        │  + 八芯反转(Rollover) RJ45 电缆
        ▼
DPR500 后面板 [RS-232 Input, RJ45 插座]
```

- 串口物理参数固定：**4800, 8N1, 无流控**（手册 Page 20；SDK 内部配置，用户无需干预）。
- 无 COM 口的工控机用 **USB→RS-232 转换器**（手册明确支持），软件通过虚拟 COM 与 SDK 工作。
- 多台 DPR500 可经 RS-232 Output 口雏菊链级联（本项目单台）。

### 3.5 控制：工控机 → ZMC（以太网）

```
工控机网口 ──网线── ZMC ETH 口
```

- 工控机网卡与 ZMC 需同网段（软件 `ConnectionConfig.IpAddress` 填控制器 IP）。
- IP 留空时软件自动回退串口方式连接（`COMx`）。

## 4. 运动系统接线

### 4.1 驱动与动力

- ZMC 每轴脉冲+方向输出 → 对应轴步进/伺服驱动器；OP8/9/10/11 → 轴 0/1/2/3 驱动器使能（上电默认断开，软件连接后按需使能）。
- 脉冲当量：5000 脉冲/圈 × 1mm/圈导程 = **5000 脉冲/mm**（软件已按此换算）。
- 软限位 ±1,500,000 脉冲 = **±300mm**（软件连接时自动写入）。

### 4.2 传感器供电

原点/限位传感器（光电/接近开关）由 ZMC 的 COM/24V 端子供电，输出接 IN 端子；全部按 **NPN 常闭**（或统一常开）规格选型，极性由软件 `INVERT_IN` 统一配置（全部不反相，`InvertIn(io,0)`）。

### 4.3 输入映射表（与软件安全初始化严格对应，勿改）

| ZMC 输入 | 轴 0（X） | 轴 1（Y） | 轴 2（Z） |
|----------|-----------|-----------|-----------|
| 正限位 FWD_IN | **IN1** | **IN4** | **IN7** |
| 负限位 REV_IN | **IN2** | **IN5** | **IN8** |
| 原点 DATUM_IN | **IN2** | **IN5** | **IN8** |

> 说明：负限位与原点共用输入口（FormRunLink 原始设计：原点开关装在负限位内侧，回零时先撞原点）。接线时 **IN1/IN4/IN7 接各轴正限位开关，IN2/IN5/IN8 接各轴负限位兼原点开关**。IN0、IN3、IN6 备用。
> 软件连接 ZMC 后自动下发：DATUM_IN=2/5/8、FWD_IN=1/4/7、REV_IN=2/5/8、InvertIn(0-8)=0、软限位 ±1500000 脉冲、Atype=1、DecelAngle=0.2618(15°)、StopAngle=0.768(44°)、CornerMode=0 —— **接线必须与上表一致，否则回零/限位失效（撞机风险）**。

## 5. 组装与上电顺序

**组装（全部断电进行）：**
1. 断电状态下开箱；佩戴防静电手环。
2. Spectrum 卡插入全长 PCIe 槽，拧紧挡板螺丝；确认机箱风扇对卡表面有风流。
3. ZMC、DPR500 装入机柜/机架；DPR500 后部通风口留 ≥10cm 散热空间。
4. 按导轨/丝杠行程安装原点与限位开关，对照 §4.3 接入 ZMC IN 端子。
5. 驱动器接线：ZMC 脉冲/方向 → 驱动器，驱动器 → 电机，OP8~11 → 使能；核对相序。
6. 接三条同轴线（§3.1/3.2）、换能器（§3.3）、串口（§3.4，含 DB9→RJ45 适配器与反转线）、网线（§3.5）。
7. DPR500 电压选择开关置 220V，检查保险丝 0.4A 250V；全部设备电源线接入带地线的 PDU。

**上电（先控制后动力、先静止后运动）：**
1. 工控机 + ZMC 控制电源 + DPR500 上电；DPR500 POWER 灯亮。
2. 工控机运行 UTscan 软件 → 连接 ZMC（软件自动下发安全初始化：原点/限位映射、软限位 ±300mm、减速度参数，并从 VRF 恢复断电前坐标）。
3. 连接 DPR500（软件经 JSR SDK 读回固件/序列号；SDK DLL 缺失或设备未连时降级仿真模式——**注意确认日志为真实连接而非 Sim**）。
4. 手动 JOG 各轴回零（先 X 后 Y 再 Z），确认限位与急停有效。
5. 设置 PRF（不超过所用脉冲发生器最大 PRF；确保前一次激励的所有回波消退后再发下一脉冲）。
6. 启动采集：Spectrum X0 收到 DPR500 同步脉冲上升沿即采集一条 A 扫 → 软件按闸门出 C 扫成像。
7. 扫描结束后软件自动关闭 X/Y 连续插补、保存 VRF 位置、断开各设备。

| 症状 | 可能原因 | 排查/解决 |
|------|---------|-----------|
| **ZMC 连接失败** | IP 不通/未上电 | `ping 192.168.0.11`；检查网线、电源；防火墙放行 |
| ZMC 运动无响应 | 轴未使能 | 确认 OP8~11 已置 1（软件"使能 XYZ"按钮）；检查驱动器使能信号 |
| 位置不更新 | 轮询定时器未启动/未连接 | 检查 ConnectAsync 返回值与 `[ZMC] 已连接` 日志 |
| 回零找不到原点 | DATUM_IN 接线错 | 对照 §4.3：轴 0→IN2、轴 1→IN5、轴 2→IN8 |
| 限位无效（撞限位不停） | FWD/REV_IN 接线错或极性反 | 对照 §4.3 映射；ZMC 工具读 `INVERT_IN` 应为 0 |
| **DPR500 连接显示 Sim** | SDK DLL 未装 / 设备未连 / 串口线没插 | 装 SDK；确认 RS-232 线（DB9→RJ45 适配器+反转线）插 **RS-232 Input** 口；`C:\Windows\SysWOW64\JSR_Common3264.dll` 存在 |
| DPR500 连上但读不到参数 | SDK 版本/固件不兼容 | 日志看 `JSR_GetAsciiInfo` 错误；确认仪器固件与 SDK 3.3.0 兼容 |
| PULSE 灯不闪 | PRF=0 或触发源错 | PRF 设为 100~5000Hz；触发源 Internal（软件 SetMode/TriggerSource） |
| **采集波形全零** | 回波线未接 / 触发未到 / 量程错 | 检查 CH0 同轴线；示波器测 X0 有同步脉冲；量程降到 ±2000mV 看信号 |
| 波形恒正/幅度异常 | 触发电平不对 | X0 电平 1000mV 适配 3~5V 脉冲；示波器确认同步脉冲幅度 |
| 帧计数不足/overrun | 消费速度不足 / 触发频率过高 | 降低 PRF 或采样点数；检查 `[DAQ] FIFO 硬件缓冲溢出` 日志 |
| 采样率设置无效 | 落入禁用空洞 | 软件自动钳位（70-72/140-144/281-287 MHz 偏移到边界）；日志确认实际值 |
| 重复启动报"采集线程已在运行" | 上次未 Stop | 属预期保护（P0-2）：先 Stop 再 Start |
| 关窗卡死 | 硬件释放慢 | 已改异步释放（3s 超时兜底），不应卡死；仍卡检查 DPR500/DAQ 通信 |
| 数据全在同一位置 | 到位判定异常 | 检查 `[ZMC]` 到位日志与限位是否截断运动（`WaitAxisSettledAsync` 抛"位置偏离目标"） |
| 软件启动即回退 Mock | hardware.json 解析失败 | 检查 `hardware.json` 为合法 JSON（**不允许 `//` 注释**，见 §8）；日志 `[装配] 解析失败` |

## 8. 软件配置（hardware.json）

真机部署时编辑 `src/UTscan/hardware.json`（构建后复制到输出目录，可执行文件目录优先）：

```json
{
  "ipAddress": "192.168.0.11",
  "port": 502,
  "serialPort": "COM1",
  "baudRate": 4800,
  "timeoutMs": 3000,
  "sampleRate": 100000000,
  "sampleCount": 1024,
  "useMock": false
}
```

| 字段 | 真机值 | 说明 |
|------|--------|------|
| `ipAddress` | ZMC 实际 IP | 留空则串口回退 |
| `serialPort` | 实际 COM 口 | 如 "COM3"（ZMC 串口回退用） |
| `sampleRate` | **Hz** 单位 | 100000000 = 100 MS/s；低于 9 MHz 会被程序回退 100 MHz（防护） |
| `sampleCount` | 每帧点数 | 与 DPR500 采样长度匹配（如 1024/2048） |
| `useMock` | **false** | 关键开关：true=模拟硬件，false=真实硬件 |

> 完整字段说明见 `docs/HARDWARE-CONFIG.md`。**注意：文件必须是标准 JSON，不得含 `//` 注释**（历史版本带注释导致解析失败静默回退 Mock——审查报告 C-1 已修复并加测试锁定）。

## 8.5 软件更新与回滚（离线现场）

> 完整方案见 `docs/软件更新方案.md`；脚本已随交付包提供（`update.cmd`/`rollback.cmd`）。

**更新（现场操作员，<5 分钟）**：
1. 关闭 UTscan.exe；
2. 将新版 `UTscan.exe` + `version.json` 拷入应用目录下的 `_update\` 子文件夹；
3. 双击 `update.cmd` → 自动：校验 SHA256 → 备份旧版（`UTscan.exe.bak-v<旧版本>`）→ 替换 → 同步 version.json；
4. 重启软件，标题栏核对新版本号，按 §6.3 抽查关键功能。

**回滚（新版本异常时）**：双击 `rollback.cmd` → 自动恢复最近备份。

**安全原则（脚本已内置）**：
- 只替换 `UTscan.exe`，**绝不覆盖** `hardware.json` 与 `%AppData%\UTscan\` 下的现场配置；
- 哈希不匹配/替换失败自动中止，旧版不受影响；
- 全程写入 `update.log` 留痕。

**版本号机制**：程序启动读取 exe 目录 `version.json`（发布脚本自动生成，含 `version`/`build`/`date`/`exeSha256`），标题栏与关于框显示真实版本；文件缺失时回退默认。现场核对版本：标题栏 `超声显微扫查系统 vX.Y.Z (YYYYMMDD)`。

## 9. 注意事项（安全第一）

- **50Ω 端接是硬性要求**：DPR500 接收输出与 TRIG/SYNC 都按 50Ω 负载设计；Spectrum CH0 已用 50Ω 路径满足；X0 为高阻 TTL 输入，同步电缆较短时直接接即可，长电缆时在 X0 端并 50Ω 终端器以消反射。
- **高压危险**：DPR500 激发电压最高 **330V**（软件钳位 0~330V），远程脉冲器连接器带高压；通电时不得插拔换能器/脉冲器电缆。功率超限时脉冲幅度下垂（软件 `GetDiagnostics` 会告警提示降低 Volts/Energy/PRF）。
- **接地**：DPR500 经电源线保护地接地；整个系统（工控机/机柜/扫描架）共地，避免地环路；同轴电缆屏蔽层两端即地。
- **EMI**：DPR500 高压脉冲能量大，回波同轴线远离动力线/驱动器线缆（交叉不并行），必要时用双屏蔽缆。
- **软限位**：±300mm 仅为软件保护，机械限位开关才是最后防线，两者都必须安装有效；首次动轴前逐轴手动触发限位确认（§6.3）。
- **急停**：调试期间手放急停按钮上；首次运动速度从 1 mm/s 起步逐步增加。
- **触发丢失**：若 A 扫幅值恒正或波形异常，检查 X0 触发电平设置（当前 1000mV）与同步脉冲幅度（3~5V）。
- **Sim 模式误用**：软件在 DPR500 未连接时自动降级仿真——真机调试务必确认连接日志显示真实型号，否则数据为模拟信号（常见误判来源）。
- **x86 平台**：全部原生 DLL 为 32 位，必须保持 `<PlatformTarget>x86</PlatformTarget>`；改 AnyCPU 会抛 BadImageFormatException。
