------------------------------------------------------------
【第 1 步】确认系统环境（一次性）
------------------------------------------------------------
□ 操作系统：Windows 10 1607 或更高（.NET 8 最低要求；Win7 不支持）
  检查：按 Win+R → 输入 winver → 回车，查看版本号
□ .NET 8.0 Desktop Runtime（x86）已安装
  下载：https://dotnet.microsoft.com/download/dotnet/8.0
  选择 .NET Desktop Runtime 8.0.x → Windows x86 安装包
□ 管理员权限：驱动安装需要管理员账号

------------------------------------------------------------
【第 2 步】安装硬件驱动与 SDK（一次性，按顺序）
------------------------------------------------------------
□ 运行 drivers\spcm_drv_install_4.0.13877.exe
   → 安装 Spectrum M3i.3242 采集卡驱动
   → 验证：设备管理器出现 Spectrum 卡（无感叹号）
□ 运行 drivers\JSRControlPanelInstaller.3.3.0.0.exe
   → 安装 JSR Common API SDK
   → 验证：C:\Windows\SysWOW64\JSR_Common3264.dll 存在
   → 装完建议重启工控机

------------------------------------------------------------
【第 3 步】放置软件
------------------------------------------------------------
□ 将 dist\release\ 整个文件夹拷贝到工控机（如 D:\UTscan\）
□ 路径建议用纯英文（避免中文路径潜在问题）

------------------------------------------------------------
【第 4 步】核对配置 hardware.json（记事本打开）
------------------------------------------------------------
  字段             当前值              需确认
  ───────────────  ──────────────────  ─────────────────────
  useMock          false（已置）       ✅ 真机模式，不要改回 true
  ipAddress        192.168.0.11        改为 ZMC 控制器实际 IP（须同网段）
  port             502                 一般不用改
  serialPort       COM1                ZMC 串口回退用（用网口可忽略）
  sampleRate       100000000           =100MS/s，按探针采样窗口调整
  sampleCount      1024                按采样长度调整（1024/2048/4096）

------------------------------------------------------------
【第 5 步】接线确认（对照 docs/接线组装指南.md §3/§4）
------------------------------------------------------------
□ 三条同轴线：DPR500 CHA 接收输出 → Spectrum CH0；DPR500 TRIG/SYNC → Spectrum X0
□ 换能器 → DPR500 CHA 远程脉冲器连接器
□ RS-232 控制线（DB9→RJ45 适配器+反转线）：工控机 COM → DPR500 RS-232 Input
□ 网线：工控机网口 → ZMC ETH（同网段）
□ 限位/原点接线：X轴 IN1/IN2、Y轴 IN4/IN5、Z轴 IN7/IN8（正限位/负限位+原点）
□ DPR500 电压选择开关置 220V

------------------------------------------------------------
【第 6 步】启动与验证（按顺序逐项打勾）
------------------------------------------------------------
□ 双击 UTscan.exe，登录（admin / 密码向管理员索取）
□ 菜单 文件→连接 → 弹出连接配置 → 确定
□ 日志面板确认：
   [ZMC] 已连接 192.168.0.11（安全初始化完成）     ← ZMC OK
   [DAQ] M3i.3242 初始化完成: 模式=FifoMulti...     ← 采集卡 OK
   [DPR500/SDK] 连接成功: DPR500 SN=...             ← 必须显示真实型号！
   ⚠ 若显示 "DPR500 (Sim)" = SDK 未找到设备（检查串口线/驱动）
□ 主窗体脉冲面板：设 PRF=1000Hz → 应用参数 → DPR500 PULSE 灯闪烁
□ 视图→A 扫显示（F2）：出现实时波形（非全零、非恒正）
□ 运动控制面板：使能 XYZ → 低速点动（速度 1mm/s）→ 坐标更新 → 急停有效
□ 回零：点"返回零点"，各轴回零正常
□ 限位测试：手动触发各轴限位开关 → 轴立即停止 + 状态栏红字报警

------------------------------------------------------------
【常见问题速查】
------------------------------------------------------------
· 启动即报"连接失败" → 看日志：IP 不通（ping ZMC）/ 驱动未装 / 串口线未插
· DPR500 显示 Sim → SDK 未找到设备，检查 RS-232 线与设备上电
· 波形全零 → 检查 CH0 同轴线 / X0 触发线 / 量程
· 扫描中拔网线 → 软件自动急停所有轴（安全联动，属正常保护）

【联调完成标准】
  A 扫波形正常 → C 扫成像出图 → 缺陷位置与试块一致（偏差≤1步距）

------------------------------------------------------------
【软件更新与回滚（版本 v1.2.0 起支持）】
------------------------------------------------------------
更新：将新版 UTscan.exe + version.json 放入本目录 _update\ 子文件夹
       → 双击 update.cmd → 自动校验SHA256/备份/替换
回滚：双击 rollback.cmd → 恢复 UTscan.exe.bak-v<版本>
说明：更新只替换 UTscan.exe，hardware.json 与 %AppData%\UTscan\ 配置不受影响。
