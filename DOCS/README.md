## 文档命名约定

- `YYYYMMDD` 后缀 = 生成/更新时间戳；
- 无后缀 = 持续维护的规范文档（接线/配置/索引）；
- 全部 UTF-8 编码，中文正文。

---

## 维护规则

1. 新文档一律放入 `DOCS/`，在 README 与本文索引登记；
2. 引用其他文档一律用相对路径 `DOCS/文件名.md`；
3. 文档移动/改名须同步更新 README 与本文引用地图；
4. 变更文档后运行 `git diff --stat` 确认无悬空引用。
